Каждый понедельник одна и та же боль: в папке лежат новые CSV из банка и 1С, а финтаблица снова просит ручной VLOOKUP и копипаст. Power Query в Excel решает это без макросов и VBA: один раз настраиваете цепочку загрузки, дальше жмёте "Обновить всё" и получаете свежий ДДС или план-факт. Ниже - когда PQ оправдан, как подключить папку с выгрузками, не сломать даты с разделителем ";" и где пора уходить в Python или Google Sheets.

Power Query (в русском Excel часто "Получить и преобразовать данные") - это встроенный ETL-слой: Extract-Transform-Load без кода. Простая аналогия для финансиста: не вы вручную перекладываете строки между книгами, а один раз описали правила приёмки выгрузок, как регламент сверки. Новый файл в папке подхватывается автоматически, если запрос настроен на "папку", а не на один жёсткий путь.

Сравнение: когда Power Query лучше ручного VLOOKUP

VLOOKUP/XLOOKUP живут хорошо, пока источник один и редко меняется. Как только выгрузки приходят пачкой (банк + 1С + CRM), формулы превращаются в хрупкий зоопарк: ссылки рвутся, листы раздуваются, новый коллега боится тронуть файл.

Критерий VLOOKUP / ручные формулы Power Query
Несколько файлов в папке Новый лист или новая формула на каждый файл Один запрос "из папки", новые CSV подхватываются сами
Очистка данных Вспомогательные колонки, TRIM, SUBSTITUTE Шаги в редакторе: типы, замены, фильтры - повторяемо
Обновление Перетащить диапазон, поправить ссылки "Обновить всё" или расписание через Power BI / службу
Аудит Формула в ячейке - сложно объяснить цепочку Список шагов Applied Steps виден в UI
Вердикт: если выгрузки регулярные и их больше одной, Power Query обычно дешевле по времени, чем ещё один слой формул. Если раз в квартал один CSV на 200 строк - хватит XLOOKUP.

Сделайте: посчитайте, сколько минут уходит на понедельничное обновление. Не делайте: тащить PQ ради одной статичной таблицы справочника на 50 строк.

Как подключить папку с выгрузками

Типичный сценарий финотдела: каждую ночь в \\share\fin\out\ или локально в C:\Fin\Staging\ падают CSV. Цель - собрать их в одну таблицу факта без ручного открытия каждого файла.

  1. Создайте папку только для "сырых" выгрузок и не смешивайте туда итоговые отчёты.
  2. В Excel: Данные → Получить данные → Из файла → Из папки (или "Объединить" для нескольких однотипных CSV).
  3. Укажите путь к папке. В предпросмотре оставьте только нужные расширения (.csv, .xlsx).
  4. Нажмите Преобразовать данные, не "Загрузить" сразу - сначала настройте шаги.
  5. В редакторе Power Query отфильтруйте скрытые/служебные файлы, оставьте колонки дата, сумма, контрагент, назначение.
  6. Объедините файлы: если структура одинаковая, используйте столбец Source.Name или Date modified для контроля свежести.
  7. Загрузите результат на лист "Fact" или только в модель данных - по вашей схеме.
Схема: Папка выгрузок → Power Query (фильтр + типы) → таблица Fact → сводные / план-факт

Если выгрузка из 1С уже идёт через OData или Excel, смотрите также выгрузку 1С в Excel через OData - PQ часто стоит вторым слоем поверх готового CSV. На первом пилоте сохраните копию "до PQ" и сравните итоговую сумму по месяцу: расхождение в копейках почти всегда тип или лишний файл в папке.

Сделайте: именовать файлы по шаблону bank_YYYYMMDD.csv. Не делайте: класть в ту же папку черновики с другой структурой колонок - запрос сломается молча.

Как настроить типы данных, даты и разделитель ";"

Русские CSV любят кодировку Windows-1251 и разделитель ";" вместо запятой. Power Query часто угадывает верно, но финансисту нельзя полагаться на угадывание: одна колонка "сумма" как текст убивает сводную.

  1. На шаге Изменить тип явно задайте: дата → Date, сумма → Decimal Number или Currency, ИНН → Text (не число - потеряете ведущие нули).
  2. Если десятичный разделитель запятая, а в файле точка - используйте Заменить значения или локаль в параметрах импорта CSV.
  3. Для дат вида 01.08.2026 выберите локаль ru-RU или задайте пользовательский формат в мастере CSV.
  4. Отключите автоматическое "Определить тип" на больших файлах: в параметрах запроса TypeDetection → None, типы задайте сами на следующем шаге.
  5. Добавьте контрольную колонку: Table.RowCount или группировку по месяцу - сравните с ожиданием из банка.

Типичная ошибка: Excel показал дату как число серийного дня Excel после обновления. Лечится принудительным типом Date до загрузки на лист. Для формул и нейросетей в соседних задачах см. нейросеть и формулы Excel для финансиста - PQ закрывает загрузку, не генерацию формул.

Сделайте: чеклист типов на первом пилоте и не меняйте порядок колонок в выгрузке без версии файла. Не делайте: грузить ИНН как число.

Обновить всё одной кнопкой

Когда запросы связаны (несколько таблиц Fact + справочники), финальная кнопка - Данные → Обновить всё. Она прогоняет все запросы книги в порядке зависимостей. Для финтаблицы это и есть "понедельник без макросов".

  • Включите Фоновое обновление, если файл тяжёлый - но следите, не открыт ли файл у коллеги с блокировкой.
  • Параметры запроса (путь к папке, период) вынесите в именованные ячейки или таблицу Config - меняете период без редактора PQ.
  • Сохраните книгу как .xlsx с подключениями; .xls не поддерживает современный PQ полноценно.
  • Для общей папки на сервере проверьте права: служба обновления Power BI или планировщик Windows должны видеть UNC-путь.

Если нужно обновление по расписанию без открытого Excel, следующий шаг - Power BI Desktop с теми же запросами или вынос тяжёлой логики в Python. Промежуточный вариант для Google-стека описан в статьях про staging в Sheets; здесь фокус на Excel desktop. Перед тем как ставить задачу IT на сервер, зафиксируйте: какие запросы must-have, сколько минут занимает ручной цикл сейчас и какой SLA нужен собственнику по понедельникам.

Сделайте: один раз прогоните "Обновить всё" с таймером и зафиксируйте время. Не делайте: прятать критичные шаги только в личной копии файла на рабочем столе.

Границы: когда уходить в Python или Sheets

Power Query не бесконечен. Я перевожу задачу в Python или Apps Script, когда:

  • файлов тысячи или суммарный объём съедает RAM на слабом ПК;
  • нужна сложная сверка с нечётким matching, которую в M-коде неудобно поддерживать;
  • источник - API с пагинацией и OAuth, а не папка CSV;
  • команде нужен один staging в облаке (Google Sheets) с триггером по времени.

Для сверки CSV на Python с pandas есть отдельный разбор в Python для финансиста: сверка CSV. PQ остаётся идеальным "первым контуром" для регулярных однотипных выгрузок в Excel; Python - когда логика переросла кнопку в UI. Гибрид тоже нормален: PQ собирает Fact, скрипт на Python один раз в неделю делает нечёткую сверку контрагентов поверх уже загруженной таблицы.

Схема выбора: регулярные однотипные CSV в LAN → Power Query; API + секреты + CI → Python; общий облачный staging → Sheets + скрипт.

Сделайте: зафиксируйте порог "если обновление > 15 минут или падает по памяти - эскалация в скрипт". Не делайте: писать 400 строк M-кода, которые проще читаются на pandas.

Что дальше

  1. Выделите папку staging и положите туда 2-3 типовых CSV.
  2. Соберите запрос "из папки" с явными типами и фильтром расширений.
  3. Проверьте суммы и количество строк против контрольного отчёта банка.
  4. Настройте "Обновить всё" и замерьте время понедельничного цикла.
  5. Если упираетесь в объём или API - спланируйте Python/Sheets, не ломайте PQ насильно.

Частые вопросы

Есть ли Power Query в Excel Online?

В браузерной версии Excel возможности "Получить и преобразовать" ограничены по сравнению с desktop. Тяжёлые запросы из папки и часть коннекторов рассчитывайте на установленный Excel для Windows или Mac - проверьте актуальный список в справке Microsoft на дату работы.

Работает ли Power Query на Mac?

Да, в Excel для Mac есть Power Query, но набор коннекторов и поведение фонового обновления могут отличаться от Windows. Пилот лучше гонять на той ОС, где будет жить боевая книга.

Нужны ли макросы, если уже есть Power Query?

Для типичной загрузки CSV - нет. Макросы остаются для UI-автоматизации (нажать кнопку, сохранить PDF), не для ETL, который PQ делает прозрачнее.

Можно ли объединить CSV с разными колонками?

Можно через "Объединить файлы" с таблицей образцов или вручную выровнять схему. Если структура плавает каждую неделю - сначала стабилизируйте выгрузку у источника, иначе поддержка съест выигрыш.

Безопасно ли хранить выгрузки в общей папке для PQ?

Технически PQ только читает. Риск - права доступа: ограничьте папку финотделом, не кладите лишние ПДн, для облачных копий действуйте политике обезличивания.

Power Query или Power BI?

Один движок M. Excel PQ - для личной/командной финкниги и сводных. Power BI - когда нужен общий дашборд, gateway и расписание без открытого Excel. Многие начинают в Excel и переносят запросы в PBIX.
