Еженедельный дайджест собственнику из Google Sheets в Telegram – это не "ещё один отчёт", а короткое сообщение: 5–7 цифр, отклонения и один вопрос "что решаем?". n8n здесь курьер: раз в неделю читает лист и шлёт текст. Ниже рабочий контур без BI и без простыни Excel в чат.

Рядом по стеку: автоматизация финансов no-code и платёжный календарь + n8n.

Выберите 5–7 цифр, которые реально читают

Собственник не открывает ваш файл с 40 вкладками. Ему нужен пульс кассы и прибыль, не полный план счетов. Дайджест – как сводка пилота перед взлётом: только критичное.

Соберите лист «Дайджест»: формулы, не копипаст

Лист digest – контракт для n8n. Каждая строка: key / label / value / comment. Value считается формулами с других листов. Ручной копипаст в value убивает смысл автоматизации.

  1. Создайте лист digest с колонками: metric_key, title_ru, value, unit, wow_delta, note.
  2. metric_key сделайте стабильным латиницей: cash_end, in_week, out_week, ar_overdue…
  3. value = ссылка/SUMIFS на факт-листы, не "вписал глазами".
  4. wow_delta – отклонение к прошлой неделе (или к плану), одной цифрой.
  5. note – коротко: "крупный платёж пятница" / пусто.
  6. Отдельная ячейка digest!B1 = дата периода ("28 Jul – 3 Aug").
Пример строк digest:
cash_end     | Остаток на счетах      | =cash!B10      | RUB |  …
in_week      | Поступления за неделю  | =SUMIFS(…)     | RUB |  …
out_week     | Списания за неделю     | =SUMIFS(…)     | RUB |  …
ar_overdue   | Просроченная ДЗ        | =ar!E2         | RUB |  …
pay_7d       | Платежи след. 7 дней   | =calendar!…    | RUB |  …
question     | Вопрос собственнику    | текст вручную  |     |  …

Сделайте: один успешный ручной пересчёт листа в понедельник. Не делайте: хранить пароли и полные выписки на этом же листе "для удобства".

Настройте n8n: раз в неделю → Telegram

n8n читает digest и собирает сообщение. Расписание – понедельник 09:00 (или день, когда цифры уже закрыты).

  1. Trigger: Schedule (Cron) – например 0 6 * * 1 UTC = 09:00 МСК понедельника.
  2. Google Sheets → Get Rows с листа digest (или Read по диапазону).
  3. Code/Set: собрать текст из title_ru + value + unit + note.
  4. Telegram node: chat_id собственника или отдельный "фин-канал".
  5. Ошибки: если value пустой – слать "digest broken: <metric_key>", не молчать.
  6. Лог: писать sent_at на служебный лист, чтобы не задвоить при ретрае.
Схема: Sheets digest (формулы) → n8n Schedule → format text → Telegram

Вопрос: переносим оплату X на пятницу?

Без n8n можно стартовать с Apps Script time-driven + UrlFetch на Telegram Bot API. n8n удобнее, когда появятся фильтры, второй канал и алерты "если остаток < порога".

Сделайте: тестовый Send сейчас, не только cron. Не делайте: слать дайджест в общий чат с подрядчиками.

Пишите текст без воды: факт / отклонение / вопрос

Шаблон трёх блоков держит дисциплину:

  • Факт – цифры периода, без эпитетов.
  • Отклонение – что выбилось vs прошлая неделя / план (1–2 строки).
  • Вопрос – одно решение на неделю, да/нет или выбор из двух.

Запрещённый стиль: "динамика положительная", "рекомендуем обратить внимание", три абзаца без числа. Если нечего спросить – вопрос = "без решений, только мониторинг".

Разборы таких контуров – в Telegram "Финансист, который кодит".

Сделайте: шаблон сообщения в закрепе чата. Не делайте: эссе на 2000 знаков в мессенджер.

Закройте безопасность: не слать ПДн и полные выписки

Дайджест – агрегаты. Не тащите в Telegram ФИО сотрудников, полные назначения платежей, сканы счетов, выгрузки 1С.

  1. В digest только суммы и короткие label.
  2. Контрагентов в тексте – обобщённо ("топ-1 дебитор"), без реквизитов.
  3. Бот и chat_id – не в публичном репо; токен только в credentials n8n.
  4. Если канал общий – отдельный приватный чат "Собственник+CFO".
  5. Раз в квартал ротация токена бота.

Сделайте: чеклист "что нельзя в дайджест" на лист rules. Не делайте: форвард сырой выписки "на всякий случай".

Частые вопросы

Можно ли в MAX вместо Telegram?

Да, если у n8n/бота есть коннектор или webhook в MAX. Логика листа digest та же – меняется только канал доставки.

Нужен ли отдельный бот?

Удобнее отдельный бот "Дайджест КОДА/фин", чтобы не мешать личным уведомлениям и проще ротировать токен.

Что если цифры к понедельнику не готовы?

Сдвиньте cron на день закрытия банка или шлите "preliminary" с пометкой в первой строке. Лучше честный статус, чем тишина.

Хватит ли Excel без Google Sheets?

Да, через OneDrive + Power Automate или экспорт в CSV для n8n. Контракт колонок digest важнее инструмента.

Как не задвоить сообщение?

Пишите sent_at / message_id на служебный лист и проверяйте перед Send. Ретраи n8n без идемпотентности = два дайджеста.

Можно ли слать только при отклонениях?

Да: Filter в n8n, если |wow_delta| > порога. Но раз в неделю "всё спокойно" тоже полезно – иначе канал ассоциируется только с плохими новостями.

Нужен ли BI?

Нет для старта. Дайджест в мессенджере закрывает ритуал решения. BI – когда метрик и людей станет кратно больше.
