Сравните обезличивание и псевдонимизацию: в чем разница по закону

Замена названия "ООО Ромашка" на "Контрагент А" в Excel – это псевдонимизация (временное маскирование), при котором данные юридически остаются персональными. Если в таблице сохранен ИНН, адрес или сумма, это ПДн. По ним легко идентифицировать лицо, и 152-ФЗ продолжает действовать. По Приказу № 140 обезличивание должно быть необратимым. Для этого нужна полная деструкция связей между субъектом и показателями. Если необратимость не гарантирована, отправка данных нарушает закон. В проектах, где я работаю, безопасность данных – это приоритет номер один, поэтому я разделяю процесс защиты на три четких шага.

Уровень 1. Как настроить ручное маскирование в Excel перед отправкой в ИИ

Алгоритм очистки таблицы

Для простых задач финансового экспресс-анализа в Excel очищайте файлы по следующему чеклисту:

  1. Удалите колонки с прямыми идентификаторами: ФИО сотрудников, ИНН, КПП, ОГРН, адреса, телефоны и email.
  2. Замените названия контрагентов на текстовые индексы через вспомогательную таблицу соответствий на скрытом листе.
  3. Уберите точные реквизиты документов. Вместо реальных номеров счетов оставьте условный индекс "Док_1".

Для рентабельности выразите расходы в процентах от выручки (100%). Для динамики замените суммы на индексы (базовый месяц – 1.0, последующие – 1.15 или 0.92). Это лишает данные ценности, сохраняя математику. Нейросеть выдаст точные выводы без реальных цифр. Логика расчетов сохраняется, а переменные скрыты.

Уровень 2. Настройте локальный прокси-фильтр в ОЗУ для работы по API

Схема работы прокси-деперсонализации

При интеграции ручное маскирование в Excel неэффективно. В этом случае софт общается с ИИ через API (цифровой курьер). Чтобы защитить контур, между учетной системой и API разворачивается локальный прокси-сервер. Схема выглядит так:

Локальный workflow деперсонализации по API:
Финансовый софт (1С) → Запрос с ПДн → Локальный прокси в ОЗУ (Маскирование) → Анонимный запрос по API → Сервер OpenAI → Анонимный ответ ИИ → Локальный прокси в ОЗУ (Размаскирование) → Готовый анализ для CFO

Для маскирования на лету используют open-source библиотеку Microsoft Presidio. Скрипт на Python находит ФИО и ИНН, заменяет их на токены, а карту соответствий держит в ОЗУ. На ИИ уходит очищенный текст, а прокси восстанавливает имена в ответе из ОЗУ. Персональные данные не пишутся на диск и не покидают сервер компании.

Пример локального Python-скрипта:

import re
class SecureProxy:
    def __init__(self): self.registry = {}
    def anonymize(self, text: str) -> str:
        for inn in re.findall(r"\b\d{10,12}\b", text):
            placeholder = f"[ИНН_{len(self.registry)+1:02d}]"
            self.registry[placeholder] = inn
            text = text.replace(inn, placeholder)
        return text
    def deanonymize(self, text: str) -> str:
        for placeholder, original in self.registry.items():
            text = text.replace(placeholder, original)
        return text

Использование такого прокси гарантирует, что ПДн физически не пересекают границу вашего сервера. Это полностью закрывает требования информационной безопасности и 152-ФЗ.

Уровень 3. Перейдите на локальные LLM в защищенном контуре

On-premise как собственный сейф в кабинете финдиректора

Для сверхчувствительных данных облачные API не подходят. Бизнес мигрирует на собственные серверы (self-hosted) – это как собственный сейф в кабинете CFO. Локальные модели позволяют анализировать первичку из 1С без отправки данных в интернет. Вычисления происходят внутри закрытого контура на вашем оборудовании.

Частые вопросы

Нарушает ли использование ChatGPT закон № 152-ФЗ?

Да, отправка нефильтрованных ПДн клиентов в OpenAI без согласия субъектов и уведомления Роскомнадзора незаконна. Обезличивайте выгрузки.

Достаточно ли заменить имя контрагента на Клиент А для защиты?

Нет. Согласно требованиям Роскомнадзора от сентября 2025 года, ИНН, номера договоров и точные суммы сделок все еще позволяют идентифицировать лицо. Необходимо маскировать все уникальные идентификаторы.

Безопасен ли платный тариф ChatGPT Team или Enterprise для финансовых данных?

Тарифы Enterprise не используют запросы для обучения. Но риск утечки из-за уязвимостей или трансграничной передачи сохраняется. Применяйте локальный прокси или on-premise.

Какие данные из 1С категорически запрещено отправлять в публичные нейросети?

Под абсолютным запретом находятся любые файлы, содержащие персональные данные сотрудников и клиентов (паспорта, ИНН, адреса, телефоны), а также первичные документы с точными реквизитами сделок и банковскими счетами.

Можно ли настроить автоматическое обезличивание без привлечения программистов?

Для Excel достаточно шаблона с формулами на скрытом листе. Для автоматизации API потребуются скрипты на Python, которые внедряются за пару часов.

Какое оборудование необходимо для запуска локальной модели типа Llama 3 для финотдела?

Для работы модели Llama 3 или Qwen на 8-14 миллиардов параметров достаточно обычного офисного компьютера с видеокартой уровня Nvidia RTX 3060/4060 с объемом видеопамяти от 12 ГБ. Это обеспечит высокую скорость генерации.
