Два CSV на столе: банк и 1С. В Excel сверка съедает вечер, в веб-чате ChatGPT – риск слить ФИО и ИНН за один копипаст. Cursor для финансиста решает иначе: открываете папку проекта, агент правит файлы через diff, терминал гоняет скрипт. За один вечер собираете скрипт сверки двух выгрузок и маленький локальный дашборд поверх тех же данных – без заказного разработчика и без сырых ПДн в публичном чате.

Cursor – это не "ещё один чат". Это среда (форк VS Code) с папкой на диске, терминалом и агентом, который читает и меняет файлы проекта. Простыми словами: чат – как переписка с консультантом по кускам таблицы; Cursor – как рабочий стол, где лежат оба CSV, скрипт и отчёт, а ИИ правит код так же, как вы правите ячейки в Excel – точечно, с контролем.

Честно: это не "корпоративный BI за вечер" и не полный гайд Cursor 2026. В моей практике цель одна – Definition of Done: файл расхождений + локальный экран с метриками. Если нужен агентный контур отчётности целиком – это другая история, Cursor AI-агенты для финотчётности. Здесь – один вечер и два артефакта.

Сравните Cursor и чат ChatGPT для рабочих файлов

Перед установкой зафиксируйте разницу. Иначе потратите час на копипаст в браузер и получите то же, что уже умеете в ChatGPT.

Скачивайте установщик только с cursor.com/download. Откройте пустую папку проекта – не весь диск C. Стартуйте в режиме Ask/Chat: "объясни структуру папки, ничего не меняй". Agent включайте, когда готовы принимать diff.

Подготовьте папку проекта: CSV, .gitignore, без сырых ПДн

Данные – как журнал проводок: структура важнее красоты. Два файла сверки (банк vs 1С или две системы) положите в data/. Скрипты – в корень или src/. Результат – в out/.

  1. Создайте папки data/, out/ и файл .gitignore.
  2. В .gitignore добавьте data/*.csv, .env, *.xlsx с ПДн.
  3. Урежьте колонки: уберите ФИО, ИНН, телефоны; контрагентов замените кодами.
  4. Суммы при необходимости замените на условные или индексы – маршрут в статье как обезличить данные перед ChatGPT.
  5. Зафиксируйте Definition of Done: ключ (номер+дата или id), поля сумм, допуск округления, выход out/mismatches.csv + краткий summary в терминале.
  6. Включите Privacy Mode в настройках Cursor, если работаете с боевыми срезами (код не идёт на обучение моделей – формулировка с cursor.com/pricing).
Схема вечера: CSV в data/ → скрипт сверки → out/mismatches.csv → мини-дашборд на localhost

Git для пилота не обязателен. .gitignore заведите всё равно: привычка дешевле утечки. API-ключи и пароли – только в .env, который в git не попадает.

Сделайте: чеклист колонок "можно / нельзя" до первого промпта. Не делайте: прикреплять сырой CSV в облачный чат агента "для контекста".

Соберите скрипт сверки двух выгрузок (сценарий 1)

Один промпт – одна задача. Agent/Composer должен получить DoD, а не "сделай красиво как в Notion". Pandas здесь – как супер-Excel: две таблицы, ключ, outer join, отчёт расхождений. JSON на выходе не нужен: хватит CSV и print в терминале.

Собери скрипт сверки на Python (pandas или csv).
Вход: data/bank.csv и data/1c.csv
Ключ: номер + дата (или колонка id – уточни по заголовкам).
Сравни суммы с допуском 0.01.
Выход: out/mismatches.csv + summary в терминале
(сколько строк, сколько совпало, сумма delta).
Кодировка: попробуй UTF-8, затем CP1251.
Разделитель: ; или , – определи сам.
Не переписывай проект целиком. Один файл скрипта.
  1. Вставьте промпт в Agent, укажите контекст через @data/ или @ имена файлов.
  2. Примите diff только по нужному .py – отклоните лишние "улучшения".
  3. Запустите скрипт в терминале Cursor. Проверьте, что появился out/mismatches.csv.
  4. Если ошибка кодировки или разделителя – короткий follow-up: "исправь только чтение CSV, остальное не трогай".
  5. Проверьте краевые случаи: пробелы в суммах, пустые ключи, дубли номеров. Править точечно (Ctrl+K / короткий чат), не "перепиши всё".

Если Python ещё не стоит – сначала установка, иначе терминал не запустит ни скрипт, ни Streamlit. Сам код агент сгенерирует; вам нужен рабочий интерпретатор и путь к нему. Я обычно сначала прогоняю сверку на 20–30 строках-заглушках, потом подставляю боевой (уже урезанный) CSV.

Сделайте: один скрипт, один отчёт, без "фреймворка сверки". Не делайте: просить агента сразу и сверку, и красивый UI, и деплой.

Поднимите маленький дашборд из той же папки (сценарий 2)

Когда mismatches.csv есть, второй артефакт – экран для глаз. Streamlit – open-source фреймворк: Python-скрипт превращается в локальную веб-страницу без фронтенд-опыта. Аналогия: сводная в Excel, только с метриками сверху и таблицей снизу, обновляется при сохранении файла.

Сделай app.py на Streamlit.
Читай out/mismatches.csv (или data/, если метрики из сырых).
Покажи: число расхождений, сумму delta, таблицу st.dataframe.
Без авторизации, без деплоя. Только localhost.
  1. Установите пакет: pip install streamlit (официальный старт – на streamlit.io).
  2. Примите app.py от агента, запустите streamlit run app.py.
  3. Откройте localhost в браузере (в Cursor 3 есть встроенный browser для локальных сайтов – удобно проверить UI).
  4. Если ставить пакеты нельзя – попросите один статический HTML с таблицей и простыми цифрами из того же CSV.
  5. Не выкладывайте боевые данные в Streamlit Community Cloud и не открывайте порт наружу "для коллег из интернета".
Правило: Streamlit быстрее для таблицы+метрик на Python. HTML – запасной путь. Оба на первом шаге только localhost / внутренняя сеть. Это прототип для себя, не BI для совета директоров.

Про идеологию "сказать на русском – получить рабочий кусок" – в vibe-coding для финансиста. Про другой инструмент того же класса – в Claude Code для финотдела. Здесь держим фокус: папка Cursor → сверка → дашборд.

Сделайте: метрики + таблица расхождений. Не делайте: промпт "сделай дашборд как в Notion" без критериев – получите гору UI без надёжных данных.

Итерируйте промптами: чеклист, чтобы не утонуть

Вайб-кодинг ломается не на первом скрипте, а на третьем "перепиши всё красивее". Финансисту нужен контроль как в акте сверки: одна правка – один результат.

  • Одна задача = один чат или одна ветка. Сверку и дашборд – разными промптами.
  • Контекст через @файл, не "посмотри весь проект".
  • Ask перед Agent на незнакомом коде: сначала объясни, потом правь.
  • Follow-up короткий: "исправь только парсинг суммы в строке 42".
  • Стоп, когда DoD выполнен: mismatches есть, дашборд открывается, цифры сходятся с ручной проверкой 3–5 строк.

Куда расти после вечера: повторный прогон на новых CSV; правила проекта (rules / AGENTS.md) – отдельная тема; MCP, чтобы не копировать файлы руками – тоже отдельно. Не смешивайте слои в одном промпте.

Сделайте: список анти-паттернов на стикер рядом с монитором. Не делайте: принимать огромный diff "потому что агент так предложил".

Частые вопросы

Платный ли Cursor?

Старт с тарифа Hobby: бесплатно, без карты, с лимитами Agent и Tab. Для регулярной агентной работы смотрите Pro ($20/мес на момент проверки 22.07.2026 на cursor.com/pricing). Teams – от $40/user/мес. Покупайте только на cursor.com, не у "серых" перекупов.

Нужен ли git для вечернего пилота?

Нет. Заведите .gitignore сразу. Git понадобится, когда делитесь папкой с коллегой или откатываете сломанный промпт.

Чем эта статья отличается от гайда про AI-агентов финотчётности?

Та – про агентный контур отчётности. Эта – один вечер: скрипт сверки двух CSV + мини-дашборд в папке Cursor. Разные Definition of Done. Читайте агентов, когда пилот сверки уже стабильно бегает.

Нужен ли Python заранее?

Желательно поставить интерпретатор и сказать агенту путь. Код сгенерируется. Без Python терминал не запустит скрипт и Streamlit – сначала мини-установка, потом промпт.

Streamlit или простой HTML?

Streamlit – если можно ставить пакеты: быстрее метрики и таблица. HTML – если пакеты нельзя. Оба на первом шаге только localhost, без выкладки боевых данных в облако.

Безопасно ли кидать выгрузки 1С в Cursor?

Сырые ПДн – нет. Урежьте колонки, обезличьте ИНН/ФИО, включите Privacy Mode, не пушьте data/ в публичный GitHub. Дашборд с боевыми данными – только localhost или внутренняя сеть.

С чего начать Cursor для начинающих в финотделе?

Скачайте с cursor.com, откройте одну папку, Ask: "объясни, не меняй". Потом один промпт сверки с DoD. Не начинайте с деплоя и MCP – сначала артефакт на диске.
