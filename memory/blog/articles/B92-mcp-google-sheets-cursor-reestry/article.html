Реестр договоров или УПД снова уезжает в чат Cursor кусками, а после правки вы вручную сверяете ячейки в Google Таблицах? MCP Google Sheets в Cursor – это розетка, через которую агент сам читает и обновляет строки реестра по ключу doc_key, без копипаста диапазонов. За 1–2 часа настроите service account и mcp-gsheets, проверите доступ через MCP Logs и прогоните сценарий: найти строку, обновить статус, перечитать результат.

MCP (Model Context Protocol) – протокол внешних инструментов Cursor. Без него агент видит только то, что вы вставили в чат; с MCP у него появляются tools к Google Sheets API, как у защищенного курьера между редактором и таблицей. Ответ в JSON – как акт сверки: у каждого поля свое место. Три маршрута на сентябрь 2026: Path B (production) – freema/mcp-gsheets + service account; Path A – Marketplace/OAuth, если Sheets в витрине; Path C – remote Google sheetsmcp.googleapis.com. Changelog Cursor от 03.08.2026 детализирует Drive, Gmail и Calendar; Sheets в релизе не расписан. Обзор MCP – в гайде по MCP в Cursor; тот же SA скриптом – в интеграции Sheets API.

Оцените, когда MCP Sheets нужен финотделу (и когда нет)

Подключайте MCP, если реестр уже в Google Таблицах (договоры, УПД, SaaS, заявки), правки еженедельные, а копипаст бесит. Не делайте Sheets единственной правдой при жестком audit trail, сотнях таблиц с enterprise ACL или более 200–300 активных договоров – тогда CLM/1С, Sheets = staging.

Подготовьте реестр и безопасность (без сырых ПДн в облако)

Одна строка = одна сущность. Колонка doc_key (DOG-2026-014) – стабильный ключ поиска. Лист staging – сырой импорт; лист "Реестр" агент правит точечно в status и comment. В облако: ИНН, сумма, статус – да; паспорт, полные ФИО payroll, карты – нет. Для тестов – "Контрагент_01" и округленные суммы. Чеклист – в гайде по обезличиванию.

SA видит только таблицы, расшаренные на client_email; IAM Cloud ≠ Share. Scope spreadsheets – на весь файл; чувствительные листы – ProtectedRange. JSON-ключ не в git.

Схема: реестр → (SA share | OAuth/remote) → MCP → update по doc_key → перечитка → регламент CFO

Сделайте: отдельный SA, share "Редактор" без "Уведомить". Не делайте: боевые ПДн в тестовый реестр.

Настройте Path B: Google Cloud, SA и mcp.json пошагово

mcp-gsheets: Node.js v20+, Sheets API, JSON SA. Конфиг – .cursor/mcp.json (проект) или ~/.cursor/mcp.json (глобально).

  1. Создайте проект в Google Cloud → Enable → Google Sheets API.
  2. Service account → Keys → JSON; скопируйте client_email; ключ вне git.
  3. Расшарьте реестр на client_email "Редактор" без уведомления. Без Share будет 403.
  4. Добавьте блок в mcp.json с абсолютным путем к ключу:
{
  "mcpServers": {
    "mcp-gsheets": {
      "command": "npx",
      "args": ["-y", "mcp-gsheets@latest"],
      "env": {
        "GOOGLE_PROJECT_ID": "your-project-id",
        "GOOGLE_APPLICATION_CREDENTIALS": "/absolute/path/to/sa-registry.json"
      }
    }
  }
}
  1. Перезапустите Cursor после правки mcp.json.
  2. Проверьте: Customize → MCPs → зеленый статус; ошибки – Output → MCP Logs; tool sheets_check_access или чтение A1:C5.
  3. Approval на write: не включайте Auto-run всех write на пилоте.

Tools: sheets_get_values, sheets_update_values, sheets_append_values, sheets_get_metadata, sheets_check_access. Для append явно INSERT_ROWS – default OVERWRITE перезаписывает не как "добавить строку".

Сделайте: зеленый сервер + check_access + чтение. Не делайте: коммит пути к ключу в git.

Подключите Path A или C для пилота (OAuth / remote)

Path A: Customize → MCPs / Marketplace. Если Sheets виден – OAuth с минимальными scopes. "Connected" ≠ авторизация: нужен живой read.

Path C: remote url https://sheetsmcp.googleapis.com/mcp/v1. В GCP – Sheets API + Sheets MCP API + OAuth. В доке Google примеры – Antigravity/Claude; Cursor – Others.

{
  "mcpServers": {
    "google-sheets": {
      "url": "https://sheetsmcp.googleapis.com/mcp/v1"
    }
  }
}

Сделайте: пилот A/C, production – B. Не делайте: верить зеленому индикатору без get_values.

Прогоните сценарий: найти, обновить, перечитать

DoD: одна строка по doc_key + diff после write. Квота: 300 write/мин на проект; при 429 – пауза, не цикл по ячейкам.

Подключись к {SPREADSHEET_ID}. На листе "Реестр" найди doc_key = DOG-2026-014.
Прочитай status и comment. Если status не "Оплачен", предложи "На согласовании"
и дату в comment. После write перечитай строку и покажи diff.
Не трогай другие листы и колонки вне status/comment.
  1. metadata – лист и заголовки на месте.
  2. Найти строку по doc_key через get_values, не угадывать номер.
  3. Approve update только status/comment.
  4. После write – перечитать ту же строку.
  5. При расхождении: "перечитай строку N, write не делай".

Indirect prompt injection: текст в ячейке может звучать как команда агенту. Human approval на каждый write. Cloud Agents не наследуют локальный OAuth – нужен SA в env или MCP из Cloud dashboard. Разборы – в Telegram "Финансист, который кодит".

Сделайте: find → update → re-read. Не делайте: Auto-run write без allowlist.

Проверьте результат и типичные ошибки

  • 403 – нет Share или неверный путь к JSON.
  • Серый MCP – MCP Logs; Node v20+; абсолютный путь в env.
  • 429 – батч, не update в цикле.
  • Append – INSERT_ROWS.
  • OAuth/remote – scopes, Sheets MCP API, живой read.

После write всегда перечитывайте диапазон. При >80–100 заявок/мес Forms→Sheets – staging перед ERP/n8n. Планируйте ротацию ключа SA и allowlist write-tools.

Сделайте: чеклист share / env / Logs / re-read. Не делайте: чинить 403 промптом без Share.

Частые вопросы

Можно ли без программиста?

Path A – да для пилота, если Sheets в витрине. Path B – по инструкции; первый реестр 1–2 часа с GCP и Share. Path C – GCP + OAuth по доке Google.

Сколько займет внедрение?

SA + mcp.json + тестовый update – около 1–2 часов. OAuth быстрее, если плагин доступен.

OAuth или service account?

OAuth – личный пилот (A/C). SA – командный реестр: только явно расшаренные файлы.

Какие риски для данных?

OAuth = права вашего Google; SA = все расшаренные таблицы. Без сырых ПДн; подтверждайте write; учтите injection из ячеек.

Чем отличается от скрипта Sheets API?

Скрипт (B82) пишет по cron. Здесь Agent правит через MCP без своего кода; тот же SA и Share.

Есть ли официальный Google Sheets MCP?

Да – remote sheetsmcp.googleapis.com (preview). Для финконтура на сентябрь 2026 надежнее mcp-gsheets + SA.

Работает ли в Cloud Agents?

Локальный OAuth не переезжает. Нужен SA в env или MCP из Cloud / Team dashboard.
