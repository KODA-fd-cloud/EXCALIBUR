## action_outline

1. **Когда нужен единый контур / когда нет** — 2+ юрлица и собственнику нужен групповой ДДС/ОПиУ → да; одно ООО и DirectBank в одной 1С → достаточно типовой загрузки (другая статья); холдинг 10+ юрлиц с МСФО → смотреть 1С:УХ / WA:Финансист (упомянуть, не продавать).
2. **Инвентаризация источников** — таблица: юрлицо, банк, р/с, формат (CSV, `1CClientBankExchange`, XML, PDF), канал (DirectBank / клиент-банк / API / e-mail), ответственный; зафиксировать периметр консолидации (какие ООО входят в управленку и почему).
3. **Единая staging-схема** — обязательные колонки: `entity_id`, `date`, `amount`, `direction`, `counterparty`, `purpose`, `bank_account`, `article_dds`, `is_intercompany`, `hash`; отдельный лист/таблица `raw_*` только append; правило дедупа по hash.
4. **Маршрут A: 1С с несколькими организациями** — DirectBank на каждый счёт каждого юрлица в одной базе Бух 3.0; выгрузка проводок/выписок в CSV для управленки или импорт в 1С:Управляющий «из документа в документ» (не сводные суммы).
5. **Маршрут B: Google Sheets master (no-code)** — папка Drive по юрлицам или IMPORTRANGE с листов-суббаз; Apps Script / Power Query аналог для нормализации; маппинг статей ДДС по ключевым словам; см. перекрёстно B36.
6. **Маршрут C: n8n / Make** — триггер по расписанию → забор файлов/API по каждому юрлицу → трансформация в единый JSON → append в Sheets/Airtable; credentials в vault, не в workflow export.
7. **Intercompany и элиминация** — справочник ИНН/названий группы; авто-флаг `is_intercompany`; при построении группового ДДС — сворачивание парных оборотов (займ А→Б = 0 на уровне группы); реестр «висяков» на 76.xx.
8. **Проверка недели 1** — сверка суммарного ЧДП группы с Δ сальдо 51/52 по всем юрлицам; 5 контрольных операций вручную; журнал ошибок; учёт комиссий и разных часовых поясов банков.
9. **Безопасность и следующий шаг** — токены банка/API только Script Properties / env n8n; обезличивание перед LLM (B11); после стабильного ДДС — автоматизация статей, платёжный календарь, audit-bridge к РСБУ.

## FAQ hints (кандидаты)

1. **Можно ли без программиста?** — Sheets + готовый шаблон / Apps Script по образцу B36: да; n8n — low-code; 1С:УХ — обычно интегратор.
2. **Сколько займёт внедрение?** — 3 юрлица, CSV+Sheets: 3–5 рабочих дней; DirectBank на все счета: 1–2 недели; полный 1С:Управляющий: от месяца.
3. **Какие риски для данных?** — облако Google, токены в Properties, не отправлять сырые выписки в ChatGPT → B11.
4. **Путают с выпиской из ЕГРЮЛ/ЕГРН 2026?** — это документ ФНС о постановке на учёт; статья про **банковские** выписки по р/с.
5. **Нужен ли 1С:Управление холдингом?** — для 2–5 ООО часто хватает Sheets/n8n + staging; УХ — при бюджетировании, ВГО по МСФО, 10+ юрлиц.
6. **Как убрать займы между своими ООО из ДДС?** — флаг intercompany + свёртка в pivot/отчёте группы.
7. **Разные банки и форматы?** — нормализация в staging; RPA или парсер Python для PDF/txt.
8. **DirectBank на все юрлица в одной базе?** — да, отдельная настройка на каждый счёт (факт №3, №5).
