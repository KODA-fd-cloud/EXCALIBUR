## reader_outcome

После гайда CFO или финансист малого финотдела за один вечер заведёт лист Справочник с 15-25 статьями ДДС (4 группы верхнего уровня), подключит выпадающие списки к листу операций, исключит разъезд названий (Аренда vs аренда офиса) и получит сходимые отчёты ДДС и план-факт из одного источника категорий.

## action_outline

1. Зафиксировать границы справочника: управленческие статьи ДДС (кассовый метод), не план счетов 1С и не КБК; цель - один код категории на все листы (Операции, План, Факт, Сводка).
2. Выбрать стартовый объём: 4 группы верхнего уровня (операционная, инвестиционная, финансовая, перемещения); внутри операционной - Поступления и Выплаты; на старте около 5-7 статей поступлений и 10-15 статей платежей, без 200 строк.
3. Создать лист Справочник с колонками: код, группа, направление (приход/расход/перевод), название, активна (да/нет), комментарий для команды; отдельная строка для переводов между счетами (не доход и не расход).
4. Запретить свободный ввод: Data Validation, выпадающий список из диапазона `Справочник!название`, режим отклонять ввод (Google Sheets / Excel); опционально зависимый список: сначала группа, потом статья.
5. Прописать правила Прочее: либо не заводить статью Прочее, либо лимит ≤5% оборота и еженедельный разбор; любая новая повторяющаяся операция - новая строка в справочнике, не правка отчёта руками.
6. Связать с операциями и staging: лист Движения или staging выписки; одна строка = одно движение денег; колонка Категория только из справочника; SUMIF/SUMIFS/QUERY на Отчёт и План-факт тянут те же коды.
7. Обучить команду одним шаблоном: памятка на 1 экран (как выбрать статью, что делать с переводом, куда писать если статьи нет); запрет дублировать категории синонимами.
8. Проверить сходимость: остаток на конец = остаток на начало + чистый поток; сверка суммы по категориям на листах Факт и Сводка; при расхождении искать опечатку вне справочника.
9. Связать с дашбордом и план-фактом: один именованный диапазон `DDS_Categories` для всех листов; при добавлении статьи обновляется только Справочник (мост к статье план-факт ДДС).

## FAQ hints (ответы-действия)

| Вопрос | Направление ответа |
| --- | --- |
| Чем отличается от плана счетов 1С? | План счетов - бухучёт; справочник ДДС - управленческие статьи по факту движения денег; можно маппить, но не копировать 1:1 |
| Можно ли 200 статей? | Можно, но на старте вредно; лимит 4 уровней, расширять по правилу существенности (повтор >5% оборота 2 месяца подряд) |
| Excel или Google Sheets? | Оба; validation одинакова по смыслу; Sheets лучше для совместного ввода командой |
| Перевод между счетами - как? | Отдельная группа Перемещения, не доход/расход; иначе раздувается выручка и OPEX |
| Что если статьи нет в списке? | Заявка финдиректору → строка в Справочник → потом операция (не наоборот) |
| Нужен ли вид движения как в 1С? | В управленческой таблице достаточно группы + направления; вид движения ПБУ критичен для регламентированного ОДДС в 1С |
| Как связать с план-фактом? | Один именованный диапазон категорий на листы План и Факт; иначе план и факт живут в разных словарях |
