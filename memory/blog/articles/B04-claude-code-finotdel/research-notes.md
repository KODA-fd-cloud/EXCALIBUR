## action_outline

1. **Установить Claude Code на Windows** — запустить PowerShell от имени администратора и выполнить команду быстрой установки `irm https://claude.ai/install.ps1 | iex` или через `winget install Anthropic.ClaudeCode`.
2. **Авторизовать аккаунт** — выполнить команду `claude` в терминале и пройти аутентификацию через браузер с использованием подписки Claude Pro.
3. **Подготовить рабочую папку с выгрузками** — создать локальную директорию (например, `C:\Finance_Analysis`), скопировать туда сырые CSV/JSON файлы из 1С или банковских выписок и перейти в неё в терминале.
4. **Запустить Claude Code в папке** — ввести команду `claude` для инициализации контекста агента в рабочей директории.
5. **Поставить задачу на анализ** — сформулировать запрос на естественном языке (например, "Сверь выписку банка bank.csv и реестр ДДС ledger.csv по сумме и дате").
6. **Контролировать выполнение Python-скрипта** — разрешить Claude Code локально сгенерировать и запустить скрипт `analyse.py` на базе pandas для обработки миллионов строк.
7. **Сохранить воспроизводимый сценарий** — попросить агента зафиксировать итоговый скрипт для ежемесячного запуска в один клик без повторного обращения к ИИ.

## FAQ hints (ответы-действия)

| Вопрос | Направление ответа |
| --- | --- |
| Безопасно ли загружать финансовые данные в Claude Code? | Да. В отличие от веб-интерфейсов, Claude Code не отправляет ваши файлы в облако целиком. Он работает локально: анализирует структуру файлов, пишет Python-скрипт (например, на pandas) и выполняет его прямо на вашем компьютере. В облако Anthropic отправляются только метаданные и запросы к модели, а сами терабайты финансовых данных обрабатываются на вашем процессоре. |
| Сколько стоит использование Claude Code? | Claude Code входит в стандартную подписку Claude Pro, которая стоит $20 в месяц (или $17 в месяц при годовой оплате). Дополнительная плата за использование CLI-агента не взимается, вы платите только за стандартные токены в рамках лимитов вашей подписки. |
| Нужны ли навыки программирования для работы с Claude Code? | Нет. Claude Code разработан для работы через естественный язык (вайб-кодинг). Вы ставите задачу на русском языке (например, "найди дубликаты платежей в файле"), а агент сам пишет нужный код на Python, запускает его, проверяет ошибки и выдает вам готовый результат в виде очищенного файла. |
