## action_outline

1. **Зафиксировать боль и критерий успеха** — счёт в живой УНФ + PDF на телефоне за минуты; не «открыть толстый клиент / полное мобильное УНФ».
2. **Выбрать канал UI** — PWA (основной в пилоте) и/или Telegram (тот же HTTP-контракт); не путать с официальным мобильным клиентом УНФ.
3. **Поставить расширение InvoiceBot** — HTTP-сервис с шаблонами `/ping`, `/counterparty`, `/nomenclature`, `/company`, `/create`; снять «Безопасный режим»; пройти метки `// ПРОВЕРИТЬ` под свою версию УНФ (1.6 vs 3.0).
4. **Создать пользователя `InvoiceBot`** — отдельная учётка, права на справочники + создание/проведение счетов; для продакшена не «Полные права».
5. **Опубликовать базу на веб-сервере** — IIS/Apache (или облачная публикация), галка HTTP-сервисов, проверка `…/hs/…/ping` → JSON `ok`.
6. **Поднять FastAPI-бэкенд + PWA** — `.env` с `ONEC_BASE_URL` / логин-пароль (или Scloud-URL), `ACCESS_CODE`; учётка 1С только на сервере, не в браузере.
7. **Прогнать сценарий с телефона** — код доступа → поиск/создание контрагента → позиции → НДС (22/10/7/5/0, в т.ч./сверху) → «Создать в 1С» → PDF.
8. **(Опционально) Telegram-бот** — тот же `/create`; whitelist `ALLOWED_CHAT_IDS`; `/ping` как smoke-test.
9. **Чеклист безопасности и ограничений пилота** — один код на команду = не прод-модель; HTTPS для нормальной установки PWA; акт в пилоте ещё урезан; исходящий паттерн для массового продукта.

## Практика pilot-unf (для writer — не выдумывать)

- **Стек:** `1c-extension/` (BSL HTTP) + `webapp/backend` (FastAPI) + `webapp/frontend` (PWA: manifest, SW, vanilla JS) + `bot/` (aiogram).
- **Контракт JSON create:** `{doc_type, counterparty:{name,inn,ref}, date, vat:{rate,included}, lines:[{name,qty,price,...}]}`.

## FAQ hints (ответы-действия)

| Вопрос | Направление ответа |
| --- | --- |
| Работает ли на УНФ 1.6 и 3.0? | Да как идея платформы; код пилота выверен под 3.0.13.x. На 1.6 — обязательный проход `// ПРОВЕРИТЬ` (имена документа/ТЧ/НДС). |
| Нужен ли программист 1С? | На установку расширения и публикацию — да (или сильный админ). На ежедневное выставление счёта с телефона — нет. |
| Можно ли только Telegram без PWA? | Да: бот бьёт в тот же HTTP-сервис (`bot/`). PWA удобнее формой и PDF; бот — запасной канал. |
| Чем лучше официального мобильного УНФ? | МП = полный клиент. Пилот = один сценарий, свой UX, секреты на сервере, PDF сразу. Если уже устраивает МП — можно не городить. |
| Это про счёт-фактуру и НДС 22%? | Нет. Статья про **счёт на оплату**. Ставку 22% в форме учесть; правила счёта-фактуры 2026 — отдельная тема. |
| Безопасно ли светить HTTP в интернет? | Для пилота — LAN/VPN/облачная публикация хостера + отдельный пользователь + код доступа. В прод — HTTPS, узкие права, whitelist, лучше исходящий контур. |
