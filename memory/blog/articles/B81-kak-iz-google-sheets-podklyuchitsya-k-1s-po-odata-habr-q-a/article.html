Excel и браузер открывают OData 1С, а Google Sheets через Apps Script отвечает "Адрес недоступен". Почти всегда виновата не "кривая" таблица, а сеть: UrlFetchApp ходит с IP Google, а не с вашего офисного ПК. Ниже – рабочий маршрут: сделать публикацию доступной по HTTPS, починить Basic Auth в скрипте, вытянуть JSON на лист raw_* и повесить кнопку "Обновить из 1С".

OData в 1С – стандартный REST-интерфейс платформы (OData 3.0): защищённый "курьер" между учётной системой и внешней таблицей. Google Apps Script – как макрос Excel в облаке Google. Вопрос с Хабра Q&A без ответов как раз про эту связку: код с credentials: 'include' падает, хотя Power Query живёт.

Общий путь Excel ↔ 1С – в выгрузке 1С в Excel через OData. Меню и кнопка в Sheets – в гайде по Apps Script для финансиста. Здесь фокус: Sheets → OData и сетевой блокер UrlFetch.

Определите, когда Sheets↔OData нужен финотделу (и когда нет)

Нужно, если регулярно тянете срез статей ДДС или движений денег в Google Sheets без "Сохранить как → Импорт". Не нужно для разовых 20 строк – быстрее CSV. Опасно тащить в облако полные карточки физлиц и сырые ПДн.

Подготовьте публикацию 1С и доступность из сети Google

Без публичного HTTPS писать Apps Script бессмысленно. Платформа 1С (от 8.3.5) публикует REST на веб-сервере (IIS или Apache): Администрирование → Публикация на веб-сервере → галка "Публиковать стандартный интерфейс OData". Состав объектов – УстановитьСоставСтандартногоИнтерфейсаOData или в БСП: Настройки стандартного интерфейса OData. Через OData недоступны отчёты, журнал регистрации и пользователи.

  1. Создайте отдельного пользователя 1С только на чтение нужных сущностей.
  2. Опубликуйте базу с галкой OData и узким составом (ДДС, статьи – без лишнего).
  3. Проверьте в браузере: https://ваш-хост/.../odata/standard.odata/$metadata с Basic Auth.
  4. Повторите URL с телефона вне Wi‑Fi офиса. Не открывается – Google тоже не достучится.
  5. Адрес не должен быть 192.168.*: UrlFetchApp не ходит в private IP и закрытый контур.
  6. Широкий whitelist всех IP из goog.json часто нереалистичен. Чаще – reverse proxy, промежуточный API или Plan B (push из локального контура).

Сделайте: readonly-пользователь + $metadata снаружи. Не делайте: открывать весь состав "как есть" и надеяться, что firewall пропустит пул Google.

Честно говоря, половина "нерабочих" скриптов с Хабра упирается именно сюда: код правильный, а публикация 1С не видна из интернета. Пока браузер с мобильного LTE не открывает $metadata – не тратьте вечер на UrlFetchApp.

Защитите данные: без сырых ПДн в облачный Sheet

Google Sheets – чужой облачный "сейф", не ваш серверный шкаф. В вопросе на Хабре тянули Catalog_ФизическиеЛица – красный флаг 152-ФЗ. Staging-лист – журнал для отчёта, не копия кадровой картотеки.

  • Берите срезы статей и ДДС с $select и $filter.
  • На отладке маскируйте ИНН/ФИО; в прод не кладите лишние поля "на будущее".
  • Логин и пароль OData – только в PropertiesService, никогда в ячейках и git.
  • Перед разбором ответов в ChatGPT/Claude обезличьте реквизиты – как в гайде по обезличиванию.

Сделайте: минимум полей на raw_*. Не делайте: выгружать физлиц "потому что сущность была в примере".

Соберите пошагово: Apps Script → OData → лист

Схема: меню "Обновить" → UrlFetchApp (Basic Auth) → JSON value[] → лист raw_* → toast
  1. Таблица → Расширения → Apps Script; сохраните скрипт, привязанный к файлу.
  2. Запишите учётные данные в Script Properties (base URL оканчивается на /odata/standard.odata).
  3. GET на $metadata, затем запрос с $format=json&$top=5 на безопасную сущность.
  4. Разберите ответ: JSON.parse → value → setValues на raw_*; при BOM срежьте первый символ.
  5. Добавьте onOpen с меню "Обновить из 1С".
  6. Режьте объём $filter/$top: timeout UrlFetch ~60 с, ответ до 50 MB, runtime до 6 мин.
function saveOnecCredentials(baseUrl, user, password) {
  PropertiesService.getScriptProperties().setProperties({
    ONEC_BASE_URL: String(baseUrl || "").replace(/\/$/, ""),
    ONEC_USER: String(user || ""),
    ONEC_PASSWORD: String(password || "")
  }, false);
}

function fetchODataTop5() {
  var p = PropertiesService.getScriptProperties();
  var base = p.getProperty("ONEC_BASE_URL");
  var user = p.getProperty("ONEC_USER");
  var pass = p.getProperty("ONEC_PASSWORD");
  var url = base + "/Catalog_SafeEntity?$format=json&$top=5";
  var token = Utilities.base64Encode(user + ":" + pass);
  var resp = UrlFetchApp.fetch(url, {
    method: "get",
    headers: { Authorization: "Basic " + token },
    muteHttpExceptions: true
  });
  if (resp.getResponseCode() !== 200) {
    throw new Error("OData HTTP " + resp.getResponseCode());
  }
  var text = resp.getContentText();
  if (text.charCodeAt(0) === 0xFEFF) text = text.slice(1);
  var rows = (JSON.parse(text).value || []).map(function (r) {
    return [r.Ref_Key, r.Description];
  });
  var sh = SpreadsheetApp.getActive().getSheetByName("raw_odata")
    || SpreadsheetApp.getActive().insertSheet("raw_odata");
  sh.clearContents();
  sh.getRange(1, 1, 1, 2).setValues([["Ref_Key", "Description"]]);
  if (rows.length) sh.getRange(2, 1, rows.length + 1, 2).setValues(rows);
}

function onOpen() {
  SpreadsheetApp.getUi().createMenu("Финансы")
    .addItem("Обновить из 1С", "fetchODataTop5").addToUi();
}

Параметр credentials: 'include' из браузерного Fetch в Apps Script не нужен – достаточно заголовка Authorization. При первом Run выдайте scope script.external_request. Квоты UrlFetch: порядка 20 000/день (consumer) и 100 000 (Workspace).

Сделайте: успех на $top=5 + меню. Не делайте: копировать браузерные сниппеты и тащить весь регистр сразу.

Проверьте результат и разберите типичные ошибки (Хабр Q&A)

Симптом: Excel видит OData, GAS пишет "Адрес недоступен". Почти всегда это маршрут – IP Google режется firewall, хост в LAN или private IP. Retry помогает при кратком сбое, но не откроет закрытую сеть.

  • Адрес недоступен – публичный HTTPS или Plan B (локальный скрипт → webapp Sheets).
  • 401 / 403 – логин, права, состав OData, сертификат HTTPS.
  • Таймаут ~60 с – режьте $top и период.
  • Пустой лист при 200 – имя сущности и BOM перед parse.
  • Authorization required – Run вручную и выдайте scopes.

Сделайте: диагностику "сеть → auth → объём → парсинг". Не делайте: крутить Basic Auth, пока $metadata не открывается с телефона вне офиса.

Что автоматизировать дальше

Когда кнопка стабильно кладёт срез на raw_*, зафиксируйте регламент: кто жмёт, какой период, куда staging. Дальше – осторожный ночной триггер, HTML-сводка или push, если 1С нельзя открывать наружу. Рядом по стеку – автоматизация финансов без кода.

Разборы таких контуров – в Telegram "Финансист, который кодит". Уроки по финконтуру – в закрытом клубе KODA.

  1. DoD: после клика raw_* заполнен, в meta есть updated_at.
  2. Добавьте период в $filter под ваш ДДС.
  3. Если GAS→1С закрыт ИБ – push локально → doPost webapp.
  4. Не пишите в 1С из Sheets по умолчанию: стартуйте с чтения.

Сделайте: один стабильный срез + rollback листа. Не делайте: обещать "whitelist трёх IP Google и заработает навсегда".

Частые вопросы

Можно ли подключить Google Sheets к 1С по OData без программиста?

Скрипт Apps Script копируется по шаблону. Публикацию OData и HTTPS один раз делает админ или 1С-ник. Финансист дальше жмёт кнопку и правит фильтр периода.

Сколько займёт внедрение связки Sheets → OData?

Если OData уже снаружи по HTTPS – вечер на скрипт и меню. Если база только в LAN – сначала инфраструктура (дни) или сразу Plan B с push.

Какие риски для данных при выгрузке в Google Sheets?

Пароль только в Script Properties; отдельный пользователь на чтение; не тащить физлиц. Перед нейросетями обезличивайте ИНН, ФИО и суммы.

Почему в Excel OData работает, а в Sheets – "Адрес недоступен"?

Excel ходит с вашего ПК. UrlFetchApp – с пула IP Google и не достучится до private IP. Сначала проверьте $metadata с телефона вне офиса.

Нужен ли IIS, чтобы публиковать OData 1С?

Нужен веб-сервер: IIS или Apache, либо облачная публикация провайдера. Без HTTP-публикации OData не заработает – это REST по HTTPS, не файл .dt.

Можно ли писать документы в 1С из Google Sheets?

Технически операции изменения есть, но для финотдела по умолчанию оставляйте только чтение. Запись – отдельный регламент и аудит.

Что делать, если 1С нельзя открывать в интернет?

Не мучайте whitelist goog.json. Выгружайте локально (Python/n8n) и пушите JSON в веб-приложение Google Sheets.
