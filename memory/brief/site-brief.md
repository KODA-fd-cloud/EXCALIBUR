# Site brief — Excalibur BLOG (КОДА)

Excalibur BLOG читает этот файл для метаданных сайта и контент-стратегии.

## Сайт

- **site_name:** КОДА — блог «Финансист, который кодит»
- **site_url:** https://koda-fd.ru
- **blog_path:** /blog/
- **language:** ru
- **niche:** автоматизация финансов и управленческого учёта, data foundation, n8n/Make, Cursor, vibe-coding, AI-агенты для CFO, интеграции 1С и банков, дашборды, GEO/SEO для финансовой аудитории

## Продукт и контент-стратегия

- **автор и эксперт:** [Ольга Кондрацкая](https://koda-fd.ru/) — финансовый директор-автоматизатор
- **открытый канал:** [Telegram «Финансист, который кодит»](https://t.me/finance_modern) — кейсы, разборы, анонсы
- **главный коммерческий оффер:** [закрытый клуб KODA](https://club.koda-fd.ru/) — уроки, материалы, доступ на club.koda-fd.ru
- **вход в клуб:** только https://club.koda-fd.ru/ (не @koda_salebot)
- **уникальный угол:** финансист, который сам собирает автоматизацию (staging → дашборд → AI), без найма разработчиков

### Тематические кластеры блога

1. **Data foundation:** staging, Excel → финконтур, качество данных, «Диснейленд для данных»
2. **n8n / Make:** банк, выписка, платёжный календарь, первичка, дайджест собственнику
3. **Cursor / vibe-coding:** дашборды, скрипты, агенты для финотчётности
4. **Нейросети для финансиста:** ChatGPT/Claude в Excel, договоры, сверки, промпты
5. **1С и MCP:** выгрузки, OData, будущие MCP-сценарии (без обещаний «магии»)
6. **GEO/SEO:** longread под Яндекс и нейровыдачу, FAQ, schema
7. **Управленческий учёт:** P&L, ОДДС, план-факт, минимализм отчётности

**Формат статей:** utility-only how-to, чеклисты, comparison, troubleshooting. Каждая статья ведёт к Telegram (прогрев) и клубу (платёжный интент).
